Meshway 将 Linux 设备组成一张由你管理的网络。节点获得 Mesh 地址，通过经过认证、端到端保护的路径通信；你在 Console 中管理成员、节点和网络策略。

## 从三个问题开始

| 你想决定什么             | 在哪里设置 | 例子                             |
| ------------------------ | ---------- | -------------------------------- |
| 谁可以访问什么           | 访问权限   | 开发组可以访问后端节点的 TCP 443 |
| 哪些节点之间允许直接连接 | 组网规则   | 两个节点只能使用 Native TCP 建连 |
| 流量必须经过哪里         | 流量路由   | 到后端的流量必须经过指定中转节点 |

三者共同决定一条可用路径。允许访问不代表已经连通；存在连接也不代表可以访问对方的所有服务。

## 你会用到的组件

- **Console**：在浏览器中选择网络、编辑配置、批准设备接入，以及查看节点状态和诊断结果。
- **服务端**：管理账户、网络身份、配置与授权，协调节点接入和连接。
- **Linux 节点**：`meshwayd` 守护进程负责运行；本机 `meshway` 命令行负责上线、下线、查看状态和探测。

每张网络有自己的成员、节点、配置和 DNS 名称。节点可以代表一个用户，也可以使用标签身份，适合按服务用途管理设备。

## 配置与实际状态

配置是你希望网络怎样运行；State 是节点实际报告的情况。编辑先进入草稿，检查并确认对照后才应用。节点随后同步和安装，你可以继续查看进度，并用 `meshway ping` 检查实际 Mesh 路径。
