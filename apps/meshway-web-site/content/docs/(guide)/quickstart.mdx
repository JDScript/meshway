## 准备条件

你需要可登录的 Meshway 控制台，以及一台已准备好 `meshwayd` 守护进程和 `meshway` CLI 的 Linux 主机。检查两台设备之间的通信时，需要第二台 Linux 主机。

请由主机运维准备并启动 daemon：明确指定服务端地址，使用默认的 `tun` 网络模式，并具备 TUN、路由和所需系统 DNS 资源的权限。CLI 与 daemon 应使用同一版本。当前控制台不提供二进制安装脚本。

以下命令连接默认 socket。使用自定义数据目录时，在命令中添加 `--socket /你的目录/control.sock`。运行 CLI 的用户须为 root 或 daemon 的同一用户。

## 1. 创建或选择网络

登录控制台。没有网络时创建第一张网络；已有网络时从网络菜单中选择。创建者成为该网络的所有者。已有账户也可以通过管理员提供的加入链接加入网络。

本指南的配置操作需要所有者或管理员权限。

## 2. 接入第一台节点

在 Linux 主机执行：

```sh
meshway up
```

首次接入时，输出会给出浏览器批准链接。打开链接，登录控制台，核对设备信息，选择网络并批准。回到终端后，daemon 会继续接入和同步。

```sh
meshway status --watch
```

在控制台的节点列表中找到设备。终端的 `Running` 表示当前目标的数据面已就绪；仅有 `ControlReady` 或已保存配置还不足以说明网络已安装。若没有批准链接，按输出联系服务端运维配置控制台地址。

### 使用接入密钥

需要标签身份时，在控制台的**添加节点**页面创建接入密钥：选择至少一个已定义的标签，填写有效期，并按需设置初始主机名和监听。没有标签时，先在配置的**Tag 所有者**中定义并应用。

密钥只显示一次。将它存入主机上的私有文件后执行：

```sh
meshway up --enrollment-key @/absolute/private/enrollment-key
```

这是一次性接入，创建的是标签身份节点；它不会把已有身份改绑到另一张网络。详见[节点与身份](/docs/concepts/identities)。

## 3. 准备两台节点之间的连接

按同样流程接入第二台节点。下文称第一台为 A、第二台为 B，`peer-name` 代表 B 在控制台中的主机名。

为了先得到一条明确的连接路径，可以在 B 的**传输**页配置 Native TCP 监听：设置监听地址、端口，以及 A 可达的公告端点。由主机运维确保该 TCP 端口实际可达。在 A 的**设置**中确认其拨号器允许 Native TCP；继承网络默认值时，检查默认集合。

同时检查**组网规则**允许 A 与 B 直接连接，且没有阻断规则或不相容的承载限制。通过[配置检查与对照](/docs/console/configuration)应用这些修改。监听不会因默认组网规则允许就自动开启。

需要 UDP 穿透或中转时，见[节点如何连接](/docs/concepts/connectivity)。

## 4. 允许访问

打开**配置 → 访问权限**，查看已有规则。新网络预置了允许 Mesh 节点互访的规则；底层默认仍是拒绝。若希望限定访问范围，应修改或删除宽泛规则，只增加一条窄规则不会收紧已有权限。

为 A 到 B 添加规则：

- **来源**：A 的节点选择器 `node:<A 的节点 ID>`。
- **目标**：B 的节点选择器 `node:<B 的节点 ID>`。
- **协议与端口**：`icmp:*`，用于下一步探测；需要访问 HTTPS 服务时再加入 `tcp:443`。
- **双向**：仅在 B 也需要主动向 A 发起相同业务时开启。回复不需要开启双向。

检查草稿，阅读修改前后对照和影响范围，再确认应用。等待节点同步。

## 5. 检查实际路径

在 A 上执行，用 B 的实际主机名替换 `peer-name`：

```sh
meshway ping peer-name -c 3
```

成功输出包含往返耗时和实际路径信息。它证明获准的 Mesh 节点路径完成了认证往返；检查 HTTPS 等应用时，还应实际访问对应服务。

若失败，依次检查：

1. 两台节点是否在线，当前配置是否已应用。
2. A 到 B 是否有 `icmp:*` 访问权限。
3. 组网规则、监听和拨号器是否有共同可用的承载。
4. 流量路由是否要求经过其他节点，而该节点不可用。

控制台的[路径检测与延迟观察](/docs/console/diagnostics)可以进一步区分配置原因与实际连接问题。

## 停止节点

```sh
meshway down
```

这会停止当前网络，保留 daemon 和节点身份。以后可以再次执行 `meshway up`。
