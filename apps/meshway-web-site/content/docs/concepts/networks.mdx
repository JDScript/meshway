---
title: 网络与成员
description: 一张网络是成员、节点和策略的管理边界。
---

网络将一组成员、节点、地址和配置放在同一管理范围内。一个账户可以加入多张网络，在不同网络中拥有不同角色。

## 三种角色

| 角色   | 日常用途                                                         |
| ------ | ---------------------------------------------------------------- |
| 所有者 | 管理网络配置、节点和成员；创建网络的人拥有此角色                 |
| 管理员 | 管理网络配置和节点，在获准范围内管理成员和加入链接               |
| 成员   | 使用自己的用户身份设备，查看与自身获准通信及其路径依赖有关的状态 |

控制台根据你当前可以执行的操作显示按钮。管理员能授予的角色有范围限制，以界面提供的选项为准。某张网络的管理权限不会延伸到另一张网络或他人的账户。

普通成员的节点列表显示自己的用户身份设备。其 State 视图可能包含获准通信所需的对端或中转信息；看得到中转节点不等于可以访问它上面的服务。

## 账户、成员与设备

账户用于登录控制台；成员关系把账户加入某张网络；节点身份用于设备接入和通信。将一个人加入网络，并不等于在网络中创建了他的设备。

加入链接用于邀请**人**。接入密钥用于接入**标签身份设备**。设备也可以用 `meshway up` 发起浏览器批准流程，以用户身份接入。

## 离开网络的影响

移除成员或离开网络会永久删除该成员当前的用户身份设备。已经使用标签身份的设备继续存在，管理员需要单独管理它们。

控制台会先展示影响，再要求确认。角色降级也可能撤销该成员签发、但新角色已无权签发的未使用加入链接。
