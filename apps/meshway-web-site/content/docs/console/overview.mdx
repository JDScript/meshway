选择网络后，总览展示节点和连接。可以从地球上的节点或节点列表打开工作区。

## 地球上的位置与连接

地球只显示已经定位的节点。没有位置的节点列在**待定位**中，并说明原因；它们不会因此被当作离线。位置接近的节点可能合成一个带数量的标记，点击后可选择具体节点。

位置来自节点公网地址的查询。浏览器会向 geojs.io 发送用于定位的公网 IP；可在账户页关闭本浏览器的位置查询。关闭后，节点会因位置查询关闭而显示为待定位。

连接线展示当前报告的连接及其状态，包括两端是否有一致证据。某一端没有位置时，连接仍会被计数和列出，但不绘制在地球上。线条本身不表示正在传输流量，也不是端到端业务成功的证明。

## 阅读节点状态

| 状态             | 下一步看什么                            |
| ---------------- | --------------------------------------- |
| 在线             | 在节点概况中继续看配置和连接            |
| 等待上线、刚重启 | 等待当前实例报告，必要时检查本机 daemon |
| 配置未同步       | 查看当前配置与节点保存、应用的版本      |
| 离线             | 查看最后在线时间和本机状态              |
| 已停用、已吊销   | 检查管理操作及配置，而不是只等待重连    |
| 状态未知         | 当前 State 中没有该节点的状态           |

在线说明报告新鲜，不能单独证明应用服务可达。节点的**概况**展示更具体的健康信息，**诊断**说明状态来自哪些报告。

## 实时更新

工具栏上的状态点说明当前视图是否正在实时更新、重连或停止。断线时 Console 会尝试恢复，并通过读取补充状态。查看问题时同时注意 State 的时间，避免把最后已知情况当成刚刚发生的事实。

新配置通知会更新已提交配置和进度，但保留你的未提交草稿。

## 历史层

开启历史层并选择时间窗口，可以查看过去打开或关闭的连接。历史连接与当前连接分开显示。时间窗口选定后是固定的，刷新才读取新的窗口。

历史可能因保留范围或收集间隙不完整，按页面显示的覆盖情况阅读。历史连接不代表现在仍能使用的路径。
