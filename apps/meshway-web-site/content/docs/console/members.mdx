title: 成员与加入链接

---

有成员管理权限时，打开**成员**，查看当前成员及加入链接。打开一名成员，可以查看角色、设备和允许执行的管理操作。

## 邀请一个人

1. 在加入链接页面创建链接。
2. 选择界面允许授予的角色和有效期（1 小时到 7 天）。
3. 复制只显示一次的链接，交给受邀人。
4. 受邀人打开链接，登录后核对网络、角色、有效期和当前账户，再确认加入。

注册入口仅在服务端开放注册时提供。已是成员的账户可以直接打开网络。链接已使用、撤销或过期，或者签发者不再有相应邀请权限时，不能继续加入。

关闭显示链接的对话框后，不能重新读取秘密值；需要时撤销旧链接并创建新链接。

加入链接用于成员，不是设备接入密钥。添加设备见[快速开始](/docs/quickstart)。

## 调整角色

打开成员并选择可授予的角色。确认前读取影响：降级可能撤销该成员签发、但新角色已无权签发的未使用加入链接。

如果成员信息已变化，控制台会重新读取，请基于最新影响再次确认。可执行的操作由服务端决定。

## 移除成员或离开网络

移除会永久删除该成员当前的用户身份设备。标签身份设备保留，不能只按最初创建者判断哪些设备会消失。

控制台会先展示影响，再要求确认。离开自己的网络也使用相同的影响确认；入口在网络设置中。需要保留设备时，先核对设备当前身份与后续管理安排。

精确操作见 [API：创建加入链接](/docs/api/members/create-join-link)、[角色变化影响](/docs/api/members/get-member-role-change-impact)和[移除成员影响](/docs/api/members/get-member-removal-impact)。
