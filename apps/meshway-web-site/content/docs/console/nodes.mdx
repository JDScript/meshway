---
title: 节点工作区
description: 查看节点健康、修改设置，并检查传输与身份。
---

在节点列表中按主机名搜索，点击节点打开工作区。所有者和管理员可查看网络中的全部节点；普通成员的列表显示自己的用户身份设备。

## 七个页签

| 页签 | 用来做什么                                                |
| ---- | --------------------------------------------------------- |
| 概况 | 先看健康、配置状态、连接数量、报告的问题、身份和地址      |
| 设置 | 查看或修改主机名、备注、启用状态、标签、Mesh 地址和拨号器 |
| 传输 | 配置监听，查看实际 socket、端点、连接和路径               |
| 延迟 | 阅读历史探测，并发起实时观察                              |
| 路径 | 检查当前配置或草稿如何为目标选路                          |
| 诊断 | 对照服务端分配目标、节点已保存与已应用配置，以及报告时间  |
| 管理 | 查看密钥、执行获准的吊销或永久删除                        |

没有相应权限时，设置只读；路径检查需要读取整网配置的权限。

## 修改设置

设置修改进入当前网络的同一份草稿，和其他配置编辑一起检查、对照和应用。Mesh 地址必须处于网络地址池内；留空某一地址族表示该节点不使用该族地址。

拨号器有三种选择：继承网络默认集合、使用自己的集合、或不主动拨号。自己的集合会替换默认集合。

给用户身份节点加标签会切换为标签身份，并改变它匹配的访问规则。修改前先阅读[节点与身份](/docs/concepts/identities)。

## 配置监听并查看实际传输

在**传输**中编辑监听，填写相应协议的地址、端口和参数。有效编辑才会进入草稿。Trojan 监听使用整份 JSONC 文档编辑。

秘密值是只写的：已有 UUID 或提供的证书在未填写新值时保留。删除后重建监听会创建新的材料；WebSocket 响应头等保留规则也会变化，按编辑器中的提示检查。

配置的监听与运行报告并排显示。检查它是否实际启动、是否报告问题，以及端点候选的来源和有效期。过期候选不能当成当前可达地址。

连接列表说明对端、实际承载、拨号方、连接阶段及业务使用情况。必要时结合**路径**和**延迟**页，进一步检查业务路径。

## 管理密钥与删除

**管理**页显示密钥及其创建时间。有权限时，可以确认吊销相应密钥或永久删除节点。旧配置不能恢复永久操作。

已有表单草稿时，删除节点加入草稿，在应用前对照中一起确认。已有 JSONC 草稿时，独立删除操作会被阻止；没有草稿时，删除经确认后直接提交。

只想暂时停用时，使用设置中的启用状态，或在主机运行 `meshway down`。

精确操作见 [API：读取节点设置](/docs/api/nodes/get-node-settings)、[吊销节点密钥](/docs/api/nodes/revoke-node-key)与[删除节点](/docs/api/nodes/delete-node)。
