# 按需执行许可

**已确认：Controller 按需计算获准候选／完整路径并补齐一致配置，设备结合 State 做最终选择和拨号。** 不预展开全网节点对，也不让设备凭自己构造的图获得新许可。

## 需求与发现

```text
Node 产生业务目标需求
  → Controller 从凭据确定 source，检查当前身份与 access
  → 根据 topology / routing / 允许方案计算有界候选及完整路径
  → 确定相关 peer / 中转 / 出口依赖与协议材料
  → 向参与节点发布相容的执行配置
  → 各 Node 独立校验／保存／应用，接收方检查相容的执行许可
  → Node query/watch 已获准依赖的 State
  → 本地选择当前可用候选并认证建连
```

请求者提交业务目标和必要协议／端口等输入，不通过自行填写中转列表或 Tag 来扩大可见范围。Controller 可以返回 preparing／unavailable；当前离线与永久未授权分别处理。

例如 A 获准访问 B，但两者需经 C：Controller 决定 C 属于执行依赖，补齐 A/C/B 所需身份、材料和许可。A 不必先猜出 C 的 ID，更不能通过 State query 自授读取或使用 C 的权限。

## 各方负责什么

| 参与方 | 职责 |
| --- | --- |
| Controller | 身份解析、业务授权、候选／完整路径计算、依赖闭包和一致发布 |
| Source Node | 在获准集合内结合当前 State 选路、选 endpoint／承载并发起业务 |
| 中转 Node | 验证自己被允许承担的完整路径角色，只转发对应流量 |
| Target／Exit | 根据自身可信配置验证认证 origin、目的范围、完整 path 及流资格 |

业务 A→B 不等于 A 必须拨 B。可以由 B 拨 A、复用双向认证通道；协议的 client/server 角色需与外层建连方式明确绑定，不能只按业务方向生成参数。

## 许可与 State

候选身份、材料、业务范围和允许路径进入受保护的 NodeConfiguration。临时地址、可达性、连接结果走 State，State 不夹带新的访问授权或秘密材料。

取得一个新中转／出口依赖时，先使所需配置完整，再使用其 State。尚未获得相容配置的接收方拒绝／等待，不信发送端附带的自制 plan。

参与节点按[普通应用流程](/v2/configuration-reference/deployment)独立处理。若必要对端尚未应用相容配置，对应业务等待／拒绝；其他节点仍可完成自己的安装。用户配置应用与后续按需发布按各自 publication 跟踪进度。

NodeConfiguration 中承载已解析计划的容器最终叫 connections 或其他名字，由 API 定义；这不改变“Controller 授权候选、设备最终选择”的职责。

## 路径与会话

- 每个候选完整路径都满足 access、topology 和 first-match routing，不通过备用路径跳过必经点。
- 当前许可绑定网络、执行发布、认证源身份／地址、业务目的范围和有序 path。
- 新流可选择不同的获准路径；一经建立／预留的流和回复保留原完整逻辑路径，故障不能偷偷改路。
- 承载主备可在同一逻辑邻接内切换；源节点自改配置不能让正常接收端认可额外路径或反向新流。

## 规模与发布

Controller 可复用同一源版本的编译事实，只对合法需求产生有界候选／切片。节点数增加不要求预计算所有简单路径，也不要求为每次实际探测重新保存管理员配置。

一次需求可以影响少量参与节点；发布引用和相关依赖必须一致，不把无关节点的状态更新视为全网权限变更。持久顺序、各节点 digest、lease 和切换规则见[同步与分发](/v2/configuration-reference/synchronization#publication)。

## 新 Controller 候选边界

隔离候选已接通持钥接入、当前配置与真实公钥库存、多个需求合并、完整节点目标与差量、实例／执行 lease、saved／applied／failed 回执及永久撤销。测试经正常建网、配置提交和接入产生 Node，HTTP／SQLite 验证不代表 Agent 已安装目标或 TUN 已通。

当前候选仍按网络重编译并替换执行发布；无关节点增量保留尚未完成。域名路由与授权的纯编译接受可信 DNS 地址关联，IP 需求同样匹配关联且许可不超过授权／路由所依赖的有效期；Controller 尚未接通可信 DNS 关联输入与远端规则集绑定，不能将编译器测试视为完整域名分流交付。自动地区选择目前只有缺失观测时的配置兜底。

Node／执行模块提供事务内 State 上报准入、当前实例／publication 可见范围和既有获准路径的观察授权接缝；统一 StateProvider、事件提交、HTTP 装配和新诊断需求合成仍须整合。地址退出记录保留未知退出下界，不因 saved／applied 释放复用限制；完整 Agent 退出证据尚未接入。
