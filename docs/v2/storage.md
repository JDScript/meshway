# Server 存储与查询

Server 私有记录的字段见[数据库](/v2/storage/database)，内存容器见[内存字段](/v2/storage/memory)。公共 Entity／Config／State 的权威来源见[数据模型](/v2/entities)；数据库有某字段不代表 API 有权返回它。

## 持久边界

| 内容 | 保存方式 |
| --- | --- |
| 配置原文、规范值、凭据、稳定绑定 | 加密的完整配置版本；原文保留编辑意图，规范值保留确定结果 |
| 接入与会话 | 私有摘要、身份／角色绑定、期限、消费与永久吊销依据 |
| 执行发布 | 精确源版本、动态依赖、完整节点切片与 digest |
| 应用结果 | 实际 receipt、实例、attempt／sequence；连续观测单独处理 |
| 规则集 | 不可变规范内容，按源版本／publication 精确绑定 |
| 地址退出 | 独立 AddressRetirement，配置回滚不清除其下界 |
| 历史 | 管理动作与观测事件分开，真实来源、去重和保留边界明确 |

Node 接入、成员移除、身份转换、配置提交及执行退出各自在其事务内保持一致。enabled 的可回滚停用和凭据的永久吊销分开。

## 数据库执行与提交

当前实现使用 SQLite／rusqlite，由有界专用线程拥有连接和事务；启用外键、WAL 与所需持久性设置。异步调用不跨 await 持有 SQL 事务，KDF／网络下载在事务外有界执行；编译是否移出事务按实际成本和一致性要求处理。

```text
读取当前基准 → 按 intent 授权 → 按 intent 写出目标草稿
  → 继承／生成材料 → 规范化 → 检查差异落在 intent 允许范围内、CAS 和依赖
  → 保存完整版本、绑定、发布、必要记录与 current 指针
  → 事务返回 (结果, effects) → COMMIT → 执行器按序应用 effects
  → 内存 journal／订阅／观察任务更新 → SSE 可见
```

每个用例是一个事务闭包，返回结果和这次提交应产生的 **effects**（配置通知、授权变化、进度变化、Node 退出、观察样本、资源变化、会话吊销）。执行器只在 COMMIT 成功后、在数据库 owner 线程上按序把 effects 交给内存 runtime；回滚一个 effect 都不产生，HTTP waiter 取消不能把提交和它的 effects 分开。effects 的数量不受 journal 保留容量限制：一次合法的批量删除可以超过 journal 能回放的条数，受影响的订阅者按 [SSE 合同](/v2/api/events)收到 reset。

已接纳的 SQL 工作独立于 HTTP waiter 完成。重试不重复创建或生成秘密。启动验证当前 schema 与完整性，错误不触发静默重置。

## 完整配置与按需查询

初版保持完整版本入库、按版本加载为不可变对象、复用解析结果；不为每次查询克隆整网配置或重解密 JSON。单节点、Tag／Group 和筛选查询在已授权版本中读取，返回的配置视图绑定 revision。

JSON 格式不要求整份 API 读写。typed ops 修改草稿后仍提交完整新版本；原始 JSONC 与注释保留规则见[编辑](/v2/configuration-reference/editing)。密文不能直接使用 SQLite JSON 函数查询。

地址索引和编译缓存可按版本重建；分配还需核对持久退出记录。只有实测需要时增加持久派生索引，并与配置指针原子切换，不建立第二份 Tag／Node 配置源。原始 JSON 文件大小不是节点容量或运行时内存承诺。

## 恢复与保留

完整历史恢复为新 revision，并重新核对身份、材料、规则集和地址退出条件。缺失／吊销依赖明确失败，不换用最新值冒充历史。Node 重启不能把缓存变成新 lease 或旧会话恢复。

最新 State、SSE 队列和探测任务有界，重启更换 epoch／重新同步；必要历史另存。清理观测正文后仍在完整接纳窗口保留去重依据及覆盖缺口。失去某个读者的可见性不等于可以删除全网报告。

备份保存一致数据库和材料主密钥；在线备份正确处理 WAL。整库恢复不能推知备份后的吊销，需协调信任与执行代际。

## 文件与客户端 {#local}

| 位置 | 内容与边界 |
| --- | --- |
| Server 部署配置 | 监听、运行目录、注册开关等；与网络业务配置分开 |
| Server 私有目录 | 数据库、锁、主密钥、必要 WAL／SHM；丢失密钥不生成替代来解读旧库 |
| Node | 长期身份、待完成接入／换钥、保存的执行目标及系统资源 journal；详见[Node 运行](/v2/node/runtime) |
| Console | 身份／网络隔离的缓存和草稿；秘密 source 仅在编辑上下文内存中 |
| 日志与临时产物 | 脱敏、有大小和保留边界，不作配置／观测数据库 |

Node 身份私钥与协议 UUID／password 用途不同。短期加密重交付只适用于有明确生命周期的接入结果，不把普通凭据摘要包装成可恢复秘密。
