# 操作权限

权限按当前网络逐请求／事务验证；持有 Node ID、Tag 名称或旧 cursor 都不是权限凭证。

## Role matrix

| 操作 | Owner／Admin | 普通成员 | 非管理员 Tag owner | Node 凭据 |
| --- | --- | --- | --- | --- |
| 修改整网配置、节点静态参数 | 本网络 | 不允许 | 不因 Tag owner 身份额外允许 | 不允许 |
| 编辑协议秘密材料（读取只见保留标记） | 本网络管理范围 | 不允许 | 不自动允许 | 只获取自身执行所需材料 |
| 赋予 Tag | 本网络有效节点 | 需具备该 Tag owner 资格 | 仅本人的 User 身份设备，且仅其拥有的 Tag | 不自行赋予身份／标签 |
| 查看 State／History | 本网络 | 自身获准业务及执行依赖的相关视图 | 与普通成员相同，不因 Tag owner 扩大范围 | 自身及获准执行所需的 peer 视图 |
| Console 主动诊断 | 本网络内的获准诊断范围 | 仅自己的 User 身份设备作为 source | 与普通成员相同 | 仅执行获准、绑定本实例的任务 |
| 选择路由方案 | 本网络任意节点（含 Tag 设备），活动记录操作者本人；受 allowed／locked 限制 | 仅自己的 User 身份设备，受 allowed／locked 限制；其他节点为 404 | 不因此管理其他 Tag 节点 | 仅自身（需当前 instance），受 allowed／locked 限制；入口见 [Routing · 选择的入口](/v2/configuration-reference/routing#选择的入口) |
| 上报 State／历史事件 | 不伪造节点报告 | 不伪造节点报告 | 不伪造节点报告 | 仅自身，绑定实例和配置上下文 |
| 读取完整配置历史／网络操作历史 | 本网络 | 不自动开放管理历史；仍可读相关观测 | 不因 Tag owner 扩大 | 不提供管理历史 |
| 永久删除 Node | 本网络，依当前管理权限 | 不因成员身份自动允许 | 不因 Tag owner 自动允许 | 仅以当前 session 删除自身（[自助注销](/v2/configuration-reference/nodes#node-self-leave)）；不以 State 上报删除身份 |

Owner／Admin 不能越过网络边界或用管理读取伪造数据面已生效。Server 提供普通注册／登录，无独立实例初始化 API；部署运维不转化为网络角色的跨网权限。

视图附当前 actions，服务端 mutation 仍重新验证。Problem 共享核心并保留各自上下文，见[Actions 与 Problem](/v2/api/problems)。

## 账户与建网

- 自助注册默认开放、可由实例配置关闭；任何有效登录用户可创建网络并成为其 Owner。注册、建网与加入网络的流程见[注册与认证](/v2/api/authentication)。
- 公开注册或创建首张网络都不授予实例管理权限；角色矩阵只适用于已加入的网络。
- 加入链接由有权管理成员者签发；Owner 可授予本网合法角色，Admin 不能签发超出自身可授予范围的角色。链接不能绕过注册关闭、成员撤销或签发权限失效。

## 成员变化的副作用

移除／离开成员会永久删除其当前 User 身份设备，按相同事务处理 membership、配置与执行退出；按创建者追溯到的 Tag 设备不在这个删除集合。有权执行该动作的人可读完整 removalImpact／nodeCount，其他视图裁剪，不借影响统计泄露隐藏节点。

角色降级同事务吊销该成员签发、而新角色已无权签发的未使用加入链接；影响预览接口见[已有账户加入网络](/v2/api/authentication#已有账户加入网络)。

[委托会话](/v2/api/authentication#delegation)继承用户的网络权限，但不能修改密码或邮箱、撤销其他会话或签发委托。无邮件密码恢复只由主机运维签发（[流程](/v2/api/authentication#无邮件账户恢复)）；任何网络 Owner／Admin 都没有他人全局账户密码重置权。账户活动仅本人，网络活动仅本网络管理读取。

## 相关视图

普通成员不是全网 State／History 读取者。其可见范围由自身获准业务，以及 topology／routing 必需的中转／出口依赖共同决定，并做字段裁剪。看得到中转入口不等于可以访问中转节点上的业务服务。

Tag 节点不再是原创建用户的 User 身份设备；创建者记录不自动赋予该用户远程诊断或秘密材料读取权限。

Realtime 任务复用也不合并权限：每个订阅者独立授权、续租和过滤结果。不能因为任务被管理员创建，后加入的普通成员就看到管理员范围的数据。

## DNS 出口的信任域 {#dns-exit-trust}

指定为某个源解析名称的 DNS 出口（netmap 中 `ServeExitResolver` 服务该源的出口节点）属于该源域名策略的信任域：它可以为所服务的源提交名称规则所决定的名称与公网地址，经 Server 校验后成为[可信域名关联](/v2/node/exit-design#trusted-dns-associations)，从而让这些地址按名称规则与 `domain:` 授权准入。Server 校验的是任务与权限（调用者是该源当前 DNS 方案的出口、名称由源的名称规则决定、地址为公网地址、TTL 与数量有界），**不独立验证 DNS 回答的真实性**：被攻破或不诚实的出口能把任意公网地址关联到它所服务名称规则的名称上。因此只应把可信的节点设为出口，管理员授予 `exitEnabled` 与配置名称规则时按这一信任关系考虑；关联不能指向私网、Mesh 或链路本地地址，也不跨源、出口或方案复用。

## 配置与材料视图

管理员可填写 UUID、password 和 TLS 材料，省略时平台按规定补全。普通成员可读视图与管理原文视图区分，使用明确类型；已保存的 UUID／password／私钥对管理员也只以[保留标记](/v2/configuration-reference/editing#secret-retained-marker)返回，回写标记即保持原值，不能当作真实密码。

局部配置操作和整份提交使用相同的最终权限判断。Tag owner 的局部赋 Tag 权限不能借整份 JSON 提交扩大为网络管理权限。
